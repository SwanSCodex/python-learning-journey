# Course 4 – Using Python to Access Web Data

This folder contains five assignments completed as part of the **University of Michigan's Python for Everybody Specialization** on Coursera.

## Assignments

| File | Description | Concepts |
|---|---|---|
| `sqlite_database_queries.py` | Creates and queries an SQLite database. | SQLite, SQL, Database Management |
| `email_organization_counter.py` | Counts email messages received from different organizations. | File Processing, Dictionaries, Data Analysis |
| `xml_music_database.py` | Parses XML music data and creates a normalized database. | XML, Python, SQL, Database Normalization |
| `many_to_many_enrollment.py` | Creates relational tables using a Many-to-Many database structure. | Relational Databases, SQL, Foreign Keys |
| `openstreetmap_geocoding.py` | Uses the OpenStreetMap Geocoding API to retrieve and visualize location data. | APIs, JSON, Geocoding, Data Visualization |

## Skills Developed

- Python programming
- SQL and SQLite database management
- XML parsing
- Relational database design
- Working with APIs
- Data processing and visualization
