# Email Data Spidering and Visualization

This project was completed as part of the University of Michigan's Python for Everybody Specialization.

## Overview

This assignment focuses on collecting email communication data through web spidering and visualizing the relationships between email addresses using a graphical model.

## Python Scripts

| File | Description |
|---|---|
| `gbasic.py` | Provides basic functionality for processing email data. |
| `gmane.py` | Handles spidering and retrieving email archive data. |
| `gmodel.py` | Generates a graphical model to visualize email communication networks. |

## Assignment Tasks

1. Start the spidering process to collect email data.
2. Run the `gmodel.py` program.
3. Generate a graphical representation of the collected email data.
4. Capture screenshots of the results.
