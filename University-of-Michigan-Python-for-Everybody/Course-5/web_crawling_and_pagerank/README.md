# Web Crawling and PageRank

This project was completed as part of the University of Michigan's Python for Everybody Specialization.

## Overview

The assignment explores web crawling, link analysis, and the PageRank algorithm using Python.

The task involves crawling 100 pages from a provided website, calculating PageRank scores, and then repeating the process with another website.

## Python Scripts

| File | Description |
|---|---|
| `spider.py` | Crawls webpages and collects links. |
| `sprank.py` | Calculates PageRank scores for crawled pages. |
| `spdump.py` | Displays the contents of the spider database. |
| `spjson.py` | Exports database information in JSON format. |
| `spreset.py` | Resets the spider database. |

## Assignment Tasks

1. Crawl 100 pages from the provided website.
2. Run the PageRank algorithm on the collected pages.
3. Capture screenshots of the results.
4. Reset the spider database.
5. Crawl 100 pages from another website.
6. Run PageRank again and capture the results.
